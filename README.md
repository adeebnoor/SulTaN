# سلطان | SULTAN

**أداة أديب نور لبناء الاستراتيجيات الحكومية وتجهيزها للتنفيذ.**

مساحة عمل عربية تربط هوية الجهة وطموحها باختيارات مبررة، ثم مرجعيات ومسارات سنوية وممكنات تشريعية ونموذج تشغيل ومبادرات ولوحة متابعة. ليست ورقة بحثية، ولا مولد نصوص من اسم الجهة، ولا حاسبة ساعات منفصلة.

## الاستخدام

1. افتح `index.html` في متصفح حديث، أو انشر محتوى `public/` بعد البناء على خدمة استضافة ثابتة.
2. اختر **ابدأ استراتيجية جديدة** أو **جرّب حالة افتراضية**.
3. عرّف الجهة وصِغ البدائل، ووثّق المقارنات المرجعية والوضع الحالي والمستهدف.
4. اضبط المعايير والأوزان وراجع المفاضلة، ثم سجل القرار ومبرره. الجاهزية الحالية لا تخفض قيمة المونشوت تلقائيًا.
5. اربط الممكنات والصلاحيات والمبادرات بالمسار السنوي، ثم راجع الفجوات والميزانية واللوحة.
6. استخدم **حفظ نسخة** لتصدير مشروع JSON قابل للاستكمال، و**تصدير الاستراتيجية** لإخراج مسودة HTML منظمة قابلة للطباعة.

## الخصوصية وحدود الإصدار

- مثال «جامعة أفق» ودرجاته ومبالغه وموافقاته افتراضية بالكامل.
- لا توجد في المستودع الوثائق الاستشارية الأصلية أو بيانات العملاء.
- مدخلات المشروع لا ترسلها الأداة إلى خادم. الحفظ المحلي غير مشفر وقد يكون غير متاح؛ ملف JSON هو النسخة الاحتياطية القابلة للنقل.
- لا ترفع ملفات مشاريع العملاء إلى هذا المستودع العام. لا تستخدم هذه النسخة للبيانات السرية.
- لا يوجد تسجيل دخول أو تحرير متزامن أو سجل تدقيق محمي أو تحقق آلي من الأدلة والأنظمة.
- الأوزان والدرجات تقديرات يحددها المستخدم، وليست احتمال نجاح أو اعتمادًا مؤسسيًا. الحساب لا يختار محفظة مثلى تلقائيًا.
- المعايير والأوزان الأولية مقترحات قابلة للتعديل، وليست معيارًا سعوديًا معتمدًا. أصالة عالمية أو تفوق ميداني لم يثبتا بهذه الاختبارات.

## التطوير

يتطلب الاختبار Node.js 22 أو أحدث، ويتطلب بناء الملف المستقل Python 3. لا توجد حزم تشغيل خارجية.

```sh
node tests/engine.test.js
python3 build.py
```

المصدر في `src/`، والاختبارات في `tests/`. يبني `build.py` نسخة مستقلة في `index.html` ومجلد `public/` للنشر. ملفات العميل ليست جزءًا من البناء.

## العلاقة بأصول المنهج

ترتكز تجربة العمل على منهجية الأمن السيبراني لصاحب المشروع (المرجعية، الوضع الحالي والمستهدف، الخارطة واللوحة)، وفلسفته عن خصوصية الجهة والطموح والمفاضلات، ومنطق وضوح البيانات والقرار والذاكرة الزمنية في «رضا». معايير القيمة الاستراتيجية وقواعد الاتساق في هذا الإصدار إضافات تصميمية؛ ليست نقلًا لمعادلة مفاضلة المعلمين.
